# Customer-Segmentation# Customer Segmentation using K-Means Clustering

## 📌 Overview
This project applies the K-Means Clustering algorithm to segment customers into distinct groups based on their purchasing behavior and characteristics. The identified clusters help businesses understand customer patterns and create targeted marketing strategies.

## 🚀 Features
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Feature scaling
- Optimal cluster selection using the Elbow Method
- Customer segmentation using K-Means Clustering
- Data visualization of customer clusters

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## 📂 Project Workflow
1. Load and preprocess the dataset.
2. Perform exploratory data analysis.
3. Scale the numerical features.
4. Determine the optimal number of clusters using the Elbow Method.
5. Train the K-Means model.
6. Visualize customer segments and interpret the results.

## 📊 Results
The model successfully groups customers into meaningful clusters, enabling businesses to identify customer segments for personalized marketing, improved customer engagement, and data-driven decision-making.

## ▶️ How to Run
1. Clone the repository.
2. Install the required libraries.
3. Open the Jupyter Notebook.
4. Run all cells to reproduce the analysis and visualizations.
